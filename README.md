# MiniGames Hub

This is a simple single-page application (SPA) built for hosting mini-games on mobile devices.

## Deployment

You can deploy this SPA with zero configuration using:
  - [Vercel](https://vercel.com/new)
  - [Netlify](https://app.netlify.com/drop)

Simply follow these steps:

1. Sign up or log in to Vercel or Netlify.
2. Click the button "Import project".
3. Follow the import wizard until you reach your dashboard.

## Features

- Mobile-first viewport optimization
- Tailwind CSS integration for styling
- Dynamic game cards loading from JSON data
- SPA routing with client-side navigation

Enjoy!
